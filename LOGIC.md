0. WEBHOOK_SERVICE -> webhook_order_status_changed.py -> transfer_order_to_ms.py

1. Получить токен Lamoda. 
    Либо он был получен при старте приложения. 

2. Получить заказ из Lamoda. 
    name - пример (RU261002-257292). 
    address - пример (LMExpress Москва, Юго-запад). 
    end_time - пример (2026-10-04 23:00:00.000). 
    invent_number[i] - пример (RU261002-257292-001, RU261002-257292-002). 
    code[i] - пример (64982-S-M, 68092-L). 
    price[i] - пример (689000, 432000). 

3. Сгенерировать номер пака. 
    packNumber - пример (FBS507B13BF8). 
    Номер пака генерируется по name. 

4. Сгенерировать наклейку пака. 
    Наклейка пака генерируется по name и packNumber. 
    В формат base64. 

5. Сгенерировать наклейки товаров. 
    Наклейки товаров генерируется по invent_number[i]. 

    5.1. Наклейки товаров в формат Base64. 
        В формат base64. 

6. Проверка наличия заказа в МС. 
    Проверка по фильтру name - пример (filter=name=RU261002-257292). 

7. Найти товары из заказа LM в МС. 
    Поиск по филтру code[i] - пример (filter=code=64982-S-M;code=68092-L). 

8. Создать заказ в МС. 

9. Добавить файлы наклеек в заказ МС.

# Логика transfer_order_to_ms.py

Модуль получает заказ из Lamoda, формирует необходимые данные и создаёт соответствующий заказ в МойСклад.
